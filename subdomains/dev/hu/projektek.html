Magas szinten optimalizált multiplatform alkalmazás, amely az érettségi felkészülési motor digitalizálására és skálázására lett tervezve. A megosztott core business logic teljesítménybeli kompromisszumok nélkül hajtja meg az Android és a célplatformok layoutjait.

A rendszer szigorúan MVI / MVVM state flow container alapra épül, így a state mutation teljesen el van választva az UI rétegtől, garantálva a zero-state leaking működést high-concurrency helyi adatbázis-tesztelés futtatása közben is.

    private val database: ExamDatabase
) {
    fun getVerifiedQuestions(subjectId: String): Flow<List<QuestionEntity>> {
        return database.examQueries
            .selectActiveQuestionsBySubject(subjectId)
            .asFlow()
            .mapToList(Dispatchers.Default)
    }
}
