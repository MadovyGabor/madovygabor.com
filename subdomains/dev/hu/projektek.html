01 / Flagship Multiplatform Architektúra

school

MaturiMate Ökoszisztéma

Kotlin Multiplatform • Aktív fejlesztés alatt

KMP Core Jetpack Compose

A MaturiMate egy érettségi-felkészítő alkalmazás Androidra és asztali gépre (JVM). Kotlin Multiplatform (KMP) és Compose Multiplatform segítségével készül, így a domain logika, az adatréteg és a felhasználói felület közös a két platformon, nem kell mindent kétszer megírni.

Az alkalmazás MVI / Clean Architecture megközelítést követ egyirányú adatfolyammal. A képernyők állapotát Kotlin Coroutines és StateFlow kezeli, így a UI frissítései kiszámíthatók és könnyebben átláthatók.

Offline-first módon működik: a kérdések és a haladás helyben, egy SQLDelighton keresztül elért relációs adatbázisban tárolódnak, a kezdeti tartalom tranzakciókon belül töltődik be, a felhasználói beállításokat pedig multiplatform DataStore menti.

class LocalExamQueries(
    private val database: ExamDatabase
) {
    fun getVerifiedQuestions(subjectId: String): Flow<List<QuestionEntity>> {
        return database.examQueries
            .selectActiveQuestionsBySubject(subjectId)
            .asFlow()
            .mapToList(Dispatchers.Default)
    }
}

02 / Enterprise Backend & Infrastruktúra

Employee & Security Auditor System

Java

Java 21 LTS nyelven írt backend alkalmazás az alkalmazotti nyilvántartás kezelésére és a munkatársak közötti biztonsági kapcsolatok kiértékelésére. A kód külön prezentációs, domain és perzisztencia rétegre tagolódik. Futás közben az adatok egy memóriában tartott repositoryban vannak, és biztonsági mentésként egy SQLite adatbázisba szinkronizálódnak. A biztonsági metrikák az alkalmazottak közötti kapcsolatok gráfjának bejárásával számolódnak, holtverseny esetén pedig egy rögzített, megismételhető szabály dönt.

A fájlműveleteket ideiglenes @TempDir könyvtárakban futó JUnit 5 tesztek fedik le, és egy GitHub Actions CI/CD pipeline minden push után automatikusan lefuttatja a teszteket.

Multi-Domain Platform & Media Pipeline

Web Ecosystem

Ez a weboldal. Egyetlen repository három különálló oldalt tartalmaz: egy fotós portfóliót, egy központi hubot és ezt a mérnöki portfóliót. Helyi fejlesztéskor együtt futnak egy Docker Compose környezetben, Alpine alapú Nginx szerverrel, így élesítés előtt ki tudom próbálni a domainek közötti routingot és a tiszta URL-eket.

A fotógalériák adatbázis nélkül készülnek. Egy kis Python CLI végignézi a képmappákat és egy JSON manifestet ír, amelyet a böngésző betölt, majd sima JavaScripttel masonry galériát épít belőle.
