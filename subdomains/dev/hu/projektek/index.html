01 / Kliensalkalmazások & Multiplatform Architektúra

school

MaturiMate Ökoszisztéma

Kotlin Multiplatform • Aktív fejlesztés alatt

KMP Core Jetpack Compose

A MaturiMate egy érettségi-felkészítő alkalmazás Androidra és asztali gépre (JVM). Kotlin Multiplatform (KMP) és Compose Multiplatform segítségével készül, így a domain logika, az adatréteg és a felhasználói felület közös a két platformon, nem kell mindent kétszer megírni.

Az alkalmazás MVI / Clean Architecture megközelítést követ egyirányú adatfolyammal. A képernyők állapotát Kotlin Coroutines és StateFlow kezeli, így a UI frissítései kiszámíthatók és könnyebben átláthatók.

Offline-first módon működik: a kérdések és a haladás helyben, egy SQLDelighton keresztül elért relációs adatbázisban tárolódnak, a kezdeti tartalom tranzakciókon belül töltődik be, a felhasználói beállításokat pedig multiplatform DataStore menti.

Employee & Security Auditor System

Java

Java 21 LTS nyelven írt backend alkalmazás az alkalmazotti nyilvántartás kezelésére és a munkatársak közötti biztonsági kapcsolatok kiértékelésére. A kód külön prezentációs, domain és perzisztencia rétegre tagolódik. Futás közben az adatok egy memóriában futó tárolóban vannak, mentésként pedig SQLite adatbázisba szinkronizálódnak. A biztonsági mutatók az alkalmazottak közötti kapcsolatgráf bejárásával számítódnak ki, és a holtversenyeket egy rögzített, megismételhető szabály dönti el.

A fájlműveleteket ideiglenes @TempDir könyvtárakban futó JUnit 5 tesztek fedik le, a tesztcsomagot pedig minden push alkalmával egy GitHub Actions CI/CD pipeline futtatja automatikusan.

03 / Fizikai Hálózati Infrastruktúra & Tűzvédelem (EPS)

Intézményi hálózat és L3 távmenedzsment

Infrastruktúra

Zöldmezős hálózat egy új oktatási intézményben: 19"-os rack, VLAN szegmentáció (menedzsment, CCTV, irodai LAN), Wi-Fi 6 és 8 IP kamera 250 W-os PoE keretről, ~80 W terheléssel.

A rögzítési streamek a PoE switch backplane-jén maradnak. Kétszintű távmenedzsment: Omada felhő a napi ellenőrzéshez, WireGuard split tunnel Brnóból az izolált alhálózatokhoz.
