01 / Vlajková loď multiplatformovej architektúry

school

Ekosystém MaturiMate

Kotlin Multiplatform • V aktívnom vývoji

KMP Core Jetpack Compose

MaturiMate je aplikácia na prípravu na maturitu pre Android a desktop (JVM). Je napísaná pomocou Kotlin Multiplatform (KMP) a Compose Multiplatform, takže doménová logika, dátová vrstva aj používateľské rozhranie sú spoločné pre obe platformy a nepíšu sa dvakrát.

Aplikácia vychádza z prístupu MVI / Clean Architecture s jednosmerným tokom dát. Stav obrazoviek držia Kotlin Coroutines a StateFlow, vďaka čomu sú aktualizácie UI predvídateľné a ľahšie sa v nich orientuje.

Funguje offline-first: otázky a pokrok sa ukladajú lokálne do relačnej databázy cez SQLDelight, počiatočný obsah sa nahráva v rámci transakcií a používateľské nastavenia sa ukladajú pomocou multiplatformového DataStore.

class LocalExamQueries(
    private val database: ExamDatabase
) {
    fun getVerifiedQuestions(subjectId: String): Flow<List<QuestionEntity>> {
        return database.examQueries
            .selectActiveQuestionsBySubject(subjectId)
            .asFlow()
            .mapToList(Dispatchers.Default)
    }
}

02 / Enterprise Backend & Infraštruktúra

layers

Employee & Security Auditor System

Java

Backendová aplikácia napísaná v Java 21 LTS na správu evidencie zamestnancov a vyhodnocovanie bezpečnostných vzťahov medzi nimi. Kód je rozdelený na samostatnú prezentačnú, doménovú a perzistenčnú vrstvu. Počas behu sa dáta držia v repozitári v pamäti a ako záloha sa synchronizujú do databázy SQLite. Bezpečnostné metriky sa počítajú prechádzaním grafu prepojení medzi zamestnancami a pri zhode rozhoduje pevné, opakovateľné pravidlo.

Operácie so súbormi pokrývajú testy JUnit 5, ktoré bežia v dočasných adresároch @TempDir, a GitHub Actions CI/CD pipeline automaticky spúšťa testy pri každom pushi.

Web Ecosystem
