MaturiMate Ecosystem

Kotlin Multiplatform • In Active Development

KMP Core Jetpack Compose

MaturiMate is an exam-preparation app for Android and desktop (JVM). It is written with Kotlin Multiplatform (KMP) and Compose Multiplatform, so the domain logic, data layer, and user interface are shared between both platforms instead of being written twice.

The app follows an MVI / Clean Architecture approach with unidirectional data flow. Screen state is held in Kotlin Coroutines and StateFlow, which keeps UI updates predictable and easier to reason about.

It works offline first: questions and progress are stored locally in a relational database through SQLDelight, the initial content is seeded inside transactions, and user settings are saved with multiplatform DataStore.

Kotlin 2.2 Compose Multiplatform SQLDelight Koin DI

Employee & Security Auditor System

Java

A backend application written in Java 21 LTS for managing employee records and evaluating their security relationships. The code is split into separate presentation, domain, and persistence layers. Data is kept in an in-memory repository while the program runs and is synchronized to a SQLite database as a backup. Security metrics are calculated by traversing the graph of connections between employees, and ties are resolved by a fixed, repeatable rule.

File operations are covered by JUnit 5 tests that run in temporary @TempDir directories, and a GitHub Actions CI/CD pipeline runs the test suite automatically on every push.

Campus Network & L3 Remote Management

Infrastructure

Greenfield network for a newly built educational facility: 19" rack, VLAN segmentation (management, CCTV, staff), Wi-Fi 6 and an 8-camera Hikvision system. Camera traffic is blocked from the internet at the gateway.

Recording streams stay on the PoE switch instead of passing through the ER605 router. The site is managed from Brno over a WireGuard split tunnel, and staff open the NVR at an internal HTTPS address with a trusted certificate.

Bosch EPS Addressable Fire Alarm & Life Safety Integration

Life Safety

Engineering, programming, and certified commissioning of an addressable fire alarm system based on the Bosch Modular Fire Panel (FPA). Incorporates multisensor optical/thermal/chemical detectors, loop sounder/strobes, and fail-safe cause-and-effect interlocks.

Validated loop resistance ($R_{\text{loop}} = 26.4\,\Omega$), calculated 24h + 30m battery backup autonomy under EN 54-4, programmed two-stage delay matrices in Bosch RPS, and executed full physical commissioning under a §21 electrical qualification.
