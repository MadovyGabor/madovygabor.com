Vysoko optimalizovaná multiplatformová aplikácia navrhnutá na digitalizáciu a škálovanie prípravy na stredoškolské maturity. Zdieľaná základná obchodná logika poháňa rozhrania pre Android aj cieľové platformy bez zníženia výkonu.

Rozhranie backendu je vybavené asynchrónnym JSON5 parsovaním spojeným s KaTeX matematickým vykresľovaním, čo umožňuje plynulé vykresľovanie zložitých algebraických matíc a testovacích modulov až po jednotlivé fragmenty zobrazenia.

Zostavené prísne v MVI / MVVM kontajneri dátových tokov (state flow). Mutácia stavu je plne oddelená od vrstvy používateľského rozhrania, čo zaručuje nulový únik stavu (zero-state leaking) počas testovania lokálnej databázy s vysokou súbežnosťou.

// Natívny cross-platformový driver na interakciu s databázou
class LocalExamQueries(
    private val database: ExamDatabase
) {
    fun getVerifiedQuestions(subjectId: String): Flow<List<QuestionEntity>> {
        return database.examQueries
            .selectActiveQuestionsBySubject(subjectId)
            .asFlow()
            .mapToList(Dispatchers.Default)
    }
}
