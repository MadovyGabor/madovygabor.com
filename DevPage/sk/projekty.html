Ekosystém MaturiMate

KMP Core Jetpack Compose

Vysoko optimalizovaná multiplatformová aplikácia navrhnutá na digitalizáciu a škálovanie systému prípravy na maturitu. Zdieľaná core business logic poháňa layouty pre Android aj cieľové platformy bez akýchkoľvek strát na výkone.

Backendové rozhranie využíva asynchrónny JSON5 parsing prepojený s KaTeX mathematical renderingom. To umožňuje plynulé vykresľovanie komplexných algebraických matíc a testovacích modulov až na úroveň jednotlivých viewport fragmentov.

Systém je striktne postavený na MVI / MVVM state flow containeri, vďaka čomu je state mutation plne oddelená od UI vrstvy, čo zaručuje zero-state leaking počas local databázového testovania s vysokou mierou concurrency.

class LocalExamQueries(
    private val database: ExamDatabase
) {
    fun getVerifiedQuestions(subjectId: String): Flow<List<QuestionEntity>> {
        return database.examQueries
            .selectActiveQuestionsBySubject(subjectId)
            .asFlow()
            .mapToList(Dispatchers.Default)
    }
}
