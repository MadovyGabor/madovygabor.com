Egy magasan optimalizált multiplatform alkalmazás, melynek célja az érettségire való felkészülés digitalizálása és skálázása. A megosztott alapvető üzleti logika teljesítményveszteség nélkül hajtja mind az Android, mind a célplatformok felületeit.

A backend interfész aszinkron JSON5 elemzést alkalmaz, mely KaTeX matematikai rendereléssel párosul, lehetővé téve komplex algebrai mátrixok és teszt modulok folyamatos megjelenítését a legapróbb nézeti fragmensekig.

Szigorúan egy MVI / MVVM állapotfolyam konténerrel építve, az állapotmutáció teljesen szét van választva az UI rétegtől, garantálva a nulla állapotszivárgást magas egyidejűségű helyi adatbázis-tesztelés során.

class LocalExamQueries(
    private val database: ExamDatabase
) {
    fun getVerifiedQuestions(subjectId: String): Flow<List<QuestionEntity>> {
        return database.examQueries
            .selectActiveQuestionsBySubject(subjectId)
            .asFlow()
            .mapToList(Dispatchers.Default)
    }
}
